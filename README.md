# PixelGear eSports Store

Landing page criada como atividade de desenvolvimento web para apresentar uma loja de produtos gamer, com foco em um computador de alto desempenho e na proposta da marca PixelGear.

## Descrição do projeto

Este projeto consiste em uma página estática de apresentação da loja `PixelGear eSports Store`, com informações sobre:

- o produto principal: `PC Gamer PixelGear Ultimate`
- a missão, metas e valores da empresa
- periféricos inclusos no pacote
- instruções de montagem do computador

A página foi desenvolvida em HTML e CSS, com uma estrutura simples e visual clean, voltada para o público gamer.

## Objetivo

Promover a marca e apresentar o produto de forma atrativa, destacando qualidade, desempenho e experiência gamer.
